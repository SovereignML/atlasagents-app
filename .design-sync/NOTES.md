# design-sync NOTES — SovereignML UI kit

This repo is a **Next.js app**, not a published component library. The synced
design system is the shadcn-style kit in `src/components/ui/` (34 components).
The sync runs the **package shape in synth/barrel-entry mode**.

## How the build is wired (non-obvious)
- **Barrel entry**: `.design-sync/entry.ts` (generated by `gen-entry.mjs`)
  re-exports every `src/components/ui/*.tsx` so esbuild bundles them into
  `window.SovereignUI`. `cfg.entry` points at it; `agent-plan` is a default
  export re-aliased as `AgentPlan`. Re-run `node .design-sync/gen-entry.mjs`
  after adding/removing a ui component, and add it to `componentSrcMap`.
- **`process` shim**: `.design-sync/process-shim.ts` is imported FIRST in the
  barrel. The kit transitively pulls modules that read `process.env.X` at
  runtime (Next router helpers); without the shim every preview throws
  "process is not defined".
- **Provider**: `.design-sync/provider.tsx` exports `ConsoleShell` (wired via
  `cfg.provider`). It (a) wraps cards in `.app-shell.console-dark` for the lime
  console theme + `dark:` variants, and (b) supplies a mock Next
  `AppRouterContext` so components calling `useRouter()` (NotFound) don't throw
  "invariant expected app router to be mounted".
- **CSS**: Tailwind v4. `.design-sync/compile-css.mjs` compiles
  `.design-sync/tw-entry.css` (imports the app's `globals.css`, scopes
  `@source` to components + previews, and promotes the **console-dark** tokens
  to `:root` so every card defaults to the lime/near-black brand look).
  Output → `.design-sync/.cache/tailwind.css` = `cfg.cssEntry`.
  **Always re-run `compile-css.mjs` before `package-build.mjs`** (a re-sync must
  recompile so preview/component utility classes are present).
- **Fonts**: `tw-entry.css` @font-face url()s are rewritten to
  `../../public/fonts/...` so the converter's extractFonts resolves + copies the
  3 local woff2 (ABC Diatype Plus, Ivar Text, Silkscreen). No `cfg.extraFonts`.
- `cfg.guidelinesGlob: []` — the repo's `docs/*.md` are internal ops docs
  (BILLING, DEPLOYMENT, INTERNAL-AUDIT…), deliberately NOT shipped.

## Staged-script patches (REQUIRED — re-apply after `cp -r` on re-sync)
The `cp -r` of staged scripts into `.ds-sync/` OVERWRITES these. Two components
(AgentPlan, NotFound) mount with framer-motion entrance animations (opacity 0)
and NotFound also reads `next/navigation`:
- `.ds-sync/package-capture.mjs` — `settle()` patched to (1) `emulateMedia
  reducedMotion:reduce`, (2) wait + `document.getAnimations().finish()` (WAAPI),
  and the fixed-clock made opt-outable via `DS_NO_FIXED_CLOCK`. NotFound was
  captured with `DS_NO_FIXED_CLOCK=1 DS_SETTLE_MS=1800` (its variant/stagger
  entrance is rAF-driven and the frozen clock stalls it; WAAPI finish misses it).
- `.ds-sync/package-validate.mjs` — added a settle (`waitForTimeout` +
  `getAnimations().finish()`) after `goto` so the render check doesn't flag
  AgentPlan/NotFound as RENDER_BLANK.
- These are local-grading-only artifacts: in the live Design pane both render
  correctly (real clock, animations complete, router mock in the bundle).

## Known render warns (triaged — not new on re-sync)
- `[FONT_REMOTE] "Geist Mono", "SF Pro Display"` — referenced in font stacks,
  served remotely/by the system. Expected, no action.
- `[GRID_OVERFLOW]` on Progress / ThemeToggle — resolved with
  `cfg.overrides.{Progress,ThemeToggle}.cardMode: "column"`.

## Theme decision
Previews default to the **console-dark** theme (lime `#a3e635` on `#0a0a0b`) —
SovereignML's signature console surface — not the marketing `:root` (blue) or
the light app-shell. Set in `tw-entry.css`'s `:root` override. To switch the
default, edit that block (and re-run compile-css + rebuild).

## Re-sync risks (watch-list)
- The staged-script patches above are wiped by `cp -r` every re-sync — RE-APPLY
  them or AgentPlan/NotFound regress to black captures and the render check fails.
- `componentSrcMap` is a fixed enumeration of the 34 ui files — if a component is
  added/removed in `src/components/ui/`, update `gen-entry.mjs` output AND the map.
- The provider's `next/dist/shared/lib/app-router-context.shared-runtime` import
  is a Next internal path — may move across Next major versions.
- `tw-entry.css` imports the app's real `globals.css`; large token/theme edits
  there flow into the kit's look automatically (usually desirable).
